Privacy Policy — YTPlay

Last updated: May 24, 2026

Chrome Extension No Data Collection Open Source

Data Collection

YTPlay does not collect, store, transmit, or sell any personal data. Period.

What the extension does

  • Voice recognition is processed locally by your browser using Chrome's built-in Web Speech API. No audio is sent to any external server.
  • Transliteration requests are sent to Google Translate's public API (translate.googleapis.com) solely to convert Hindi/Devanagari text to Roman script. No user identifiers are attached to these requests.
  • Language preference is stored locally on your device using localStorage. It never leaves your browser.

Third-party services

Service Purpose Data sent
Chrome Web Speech API Voice recognition Audio processed locally by Chrome
Google Translate API Transliterate Devanagari to Roman Only the recognized text (no user ID, no cookies)

Permissions

host_permissions: translate.googleapis.com — Required solely for Hindi/Devanagari transliteration. No other permissions are requested.

Data storage

All preferences are stored in your browser's localStorage. No external databases, no accounts, no cookies, no analytics.
